Primero instala Python https://www.python.org/downloads/



luego abre un cmd (win+R) y escribe cmd en el recuadro que sale seguido de eso pega esto 
     -   pip install yt-dlp instaloader   - esto descargara yt-dlp e instaloader para yt fb ig y otros sitios soportados por ytdlp 


seguido de eso pega esto para descargar la dependencia de el monitor de links 

pip install pyperclip keyboard 

asimismo recomiendo descargar la extensión en su navegador llamado Get cookies.txt LOCALLY 
esto permitirá obtener las cookies del navegador (por si el video a descargar necesita verificación para no ser detectado como bot o si la pagina no lo deja 



Si la primera descarga falla prueba a descargar los componentes faltantes o estas dependencias (recomendable ejecutar unitariamente)

winget install FFmpeg

winget install Denoland.Deno

npm install -g @yt-dlp/ejs

pip install --upgrade yt-dlp 


si no se inician o tira error de descarga prueba descargar winget (usualmente puede fallar por no tener la tienda de descarga instalada)
